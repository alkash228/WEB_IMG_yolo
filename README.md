# WEB_IMG_yolo

1. Запустите SAM3 API (по умолчанию `http://127.0.0.1:8080`).
2. `run.cmd` или `run.ps1` — UI на http://localhost:8091
3. Выберите папку с картинками → «Собрать датасет» → скачайте ZIP из `output/<timestamp>/`.

Кадры без хотя бы одного бокса субъекта (голова) не попадают в train/val и не создают пустых `.txt`.
